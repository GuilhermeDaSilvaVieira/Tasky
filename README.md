# Tasky

Tasky is a web-based task management app built with FastAPI, PostgreSQL, Vue.js (TypeScript), Tailwind CSS, and Ionic. It allows users to manage tasks with features like task nesting, advanced filtering, real-time collaboration, and a mobile-friendly interface.

## Features

- **Nested Tasks**: Create tasks within tasks for better organization.
- **Task Details**: Each task includes title, description, status, due date, and importance.
- **Dark and Light Themes**: Switch between dark and light themes for personalized user experience.
- **Search**: Quickly find tasks with a powerful search feature.
- **Task Filtering**: Filter tasks by status, importance, and due date.
- **Real-time Collaboration**: Work with others in real-time, with instant task updates.
- **Notifications**: Receive notifications for task updates, due dates, and status changes.
- **Mobile Support**: Built with Ionic to easily convert into a mobile app.

## Tech Stack

- **Backend**: FastAPI (Python)
- **Database**: PostgreSQL
- **Frontend**: Vue.js (TypeScript), Tailwind CSS, Ionic
- **Migrations**: Alembic
- **Authentication**: JWT
